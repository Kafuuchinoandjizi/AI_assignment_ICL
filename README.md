# AI_assignment_ICL

人工智能原理与应用大作业

ICL上下文学习

要求：

​	一、任务介绍 研究不同提示策略在分类、抽取、推理等小任务上的效果与代价（准确率、成本、 时延），并尝试用 DSPy 等工具做自动提示或程序化提示优		化。

​	 二、任务要求 基础：选择 2–3 个子任务，系统对比不同提示策略；记录每类策略的性能与推 理成本。 进阶：使用 DSPy 做提示/模块自动化搜索，或用 LM-		Eval-Harness 统一评测多任 务；加入自一致性采样与多数投票。 Demo：交互页面可切换提示策略，展示预测、思维过程摘要与耗时。 

​	三、数据与环境 设备建议：CPU 可行，GPU 更快；Python 3.10+。 工具建议：DSPy（程序化提示与自动化搜索）；LM-Eval-Harness（统一评测）

​	四、参考文献 Large Language Models are Zero-Shot Reasoners（Chain-of-Thought） Self-Consistency Improves Chain-of-Thought Reasoning 	

​	五、示例代码仓库 DSPy LM-Eval-Harness
